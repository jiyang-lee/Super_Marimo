# 팀원 브랜치 시작 안내

이 문서는 `govl3773-spe`가 이 레포에서 프론트 작업을 시작할 때 쓰는 안내문이다.

## 기본 원칙
- 이 레포는 하나만 쓴다.
- 프론트 작업은 `frontend/*` 브랜치에서만 한다.
- `main`에는 직접 커밋하지 않는다.
- 작업이 끝나면 PR로 `main`에 합친다.

## 처음 할 일
1. 레포를 clone 한다.
2. 최신 `main`을 받는다.
3. `frontend/*` 형식의 브랜치를 만든다.
4. 그 브랜치에서만 커밋한다.
5. 원격에 push 한다.
6. PR을 연다.

## 명령어 예시
```powershell
git clone https://github.com/jiyang-lee/Super_Marimo.git
cd Super_Marimo
git checkout main
git pull origin main
git checkout -b frontend/<작업명>
git add .
git commit -m "feat: 프론트 작업 내용"
git push -u origin frontend/<작업명>
```

## 브랜치명 예시
- `frontend/login-page`
- `frontend/main-layout`
- `frontend/dashboard-redesign`

## PR 올릴 때
- 제목에 작업 내용이 보이게 쓴다.
- 변경 이유를 적는다.
- 검증 방법을 적는다.
- 남은 이슈가 있으면 적는다.
- 백엔드와 충돌하면 먼저 이야기한다.

## 주의점
- 기존 프론트를 이어서 고치는 방식이 아니라 새 구조로 만들어도 된다.
- 브랜치가 프론트 작업임을 이름으로 보여줘야 한다.
- 커밋은 자기 브랜치에만 남긴다.
