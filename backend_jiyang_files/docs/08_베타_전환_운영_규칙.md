# 베타 전환 운영 규칙

## 현재 기준
- Goal의 구조는 유지한다.
- 실제 구현은 RP2040 단일 환경에서 검증 가능한 최소 경로부터 안정화한다.
- 현재 단계의 핵심은 음성 이벤트 저장과 실제 TTS이다.

## 유지할 것
- `voice-agent`: 오케스트레이션
- `voice-server`: STT / TTS
- `api-server`: 저장 / 세션 / 이벤트 / 센서 상태
- `wakeword`
- `manual-test`
- `voice/ask`
- `voice-server /tts`

## 보류할 것
- 거리센서 기반 `sensor-warning`
- `proactive_greeting`
- 거리 쿨다운
- 호출어 생명주기 전체 로그 분해
- 입력 장치 분리 서비스 추가

## 보고서 규칙
- 서버 구조 또는 DB 구조가 바뀌면 반드시 `report/`에 보고서를 남긴다.
- 보고서의 최상단에는 수정된 다이어그램을 넣는다.
- 보고서에는 현재 구조, 변경 구조, 검증 결과, 보류 항목을 같이 적는다.

## Git / GitHub 규칙
- 작업 브랜치는 `backend/jiyang`을 사용한다.
- 커밋 메시지는 한글로 작성한다.
- 기능 단위로 커밋을 나눈다.
- 큰 작업은 커밋 후 `push`하고 PR로 정리한다.
