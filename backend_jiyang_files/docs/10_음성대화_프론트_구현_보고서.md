# 음성대화 프론트 구현 보고서

## 작업 목표

- RP2040/시리얼 음성 루프에서 하던 대화 흐름을 프론트 중심으로 옮긴다.
- 페르소나 선택기와 TTS 목소리 선택기를 추가한다.
- 세션 목록과 대화 상세를 프론트에서 바로 보이게 한다.
- 전체 화면을 더 밝고 알록달록한 톤으로 바꾼다.

## 반영 내용

### 1. 프론트 대화 화면 재구성

- `frontend/src/App.tsx`를 대화 중심 화면으로 다시 구성했다.
- 브라우저 `mic` 버튼으로 음성 인식을 시작할 수 있게 했다.
- 입력한 문장을 `voice-agent`로 보내고, 응답을 브라우저에서 TTS로 재생하도록 연결했다.
- 자동 TTS 토글을 추가해서 답변을 바로 재생하거나 끌 수 있게 했다.

### 2. 페르소나 선택기 추가

- `꼬마 기본`, `밝은 꼬마`, `차분한 꼬마`, `직접 입력` 프리셋을 넣었다.
- 선택한 페르소나 메모는 `voice-agent -> api-server -> llm-server`로 전달되도록 연결했다.
- LLM 기본 페르소나도 같은 꼬마 말투로 맞췄다.

### 3. TTS 목소리 선택기 추가

- `voice-server /health`에 사용 가능한 TTS 목소리 이름 목록을 노출했다.
- 프론트에서 목록을 받아 dropdown으로 선택할 수 있게 했다.
- `/tts` 요청에 `voice_name`을 실어 원하는 목소리로 재생하게 했다.

### 4. 세션 표시 강화

- `Command sessions` 패널로 최근 세션을 프론트에서 바로 확인할 수 있게 했다.
- 선택한 세션의 상세 메시지와 메타를 같이 보여주도록 유지했다.

### 5. 화면 스타일 개선

- 어두운 모니터링 톤을 걷어내고 밝은 그라디언트 배경으로 바꿨다.
- 카드, 버튼, 세션 리스트를 유리질감 + 컬러 포인트 스타일로 정리했다.
- 전체 UI를 브라우저에서 더 가볍고 친근하게 보이도록 조정했다.

## 백엔드 연결 변경

- `api_server`
  - `persona_memo`, `system_memo`를 LLM 요청에 전달
  - 세션/음성 대화 루프에 새 메모 값 반영
- `voice_agent`
  - 프론트에서 받은 페르소나, 목소리 이름, TTS 옵션을 전달
  - 도커 기준 프록시와 맞추기 위해 기본 포트를 `8003`으로 유지
- `voice_server`
  - `tts_voice_names`를 health 응답에 추가
  - 요청별 `voice_name` 선택 지원
