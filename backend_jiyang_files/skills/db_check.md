# db_check

## 언제 쓰나
- DB 테이블 존재 여부를 볼 때
- 저장이 실제로 되었는지 확인할 때
- 스키마나 쿼리 결과를 점검할 때

## 사용자에게 받을 것
- 확인할 DB 이름
- 연결 방식
- 확인할 테이블 또는 쿼리
- 성공 기준

## 진행 순서
1. 연결 정보를 확인한다.
2. 테이블 목록이나 쿼리를 확인한다.
3. 저장 여부와 행 수를 본다.
4. 필요한 경우 오류 원인을 좁힌다.

## 출력 기준
- 테이블명, 행 수, 상태가 보인다.
- 성공/실패가 분명해야 한다.

## 완료 기준
- DB가 살아 있는지, 저장이 되는지 바로 판단할 수 있다.
