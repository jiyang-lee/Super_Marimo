# 스킬 가이드

이 문서는 자주 하는 작업을 같은 방식으로 반복하기 위한 입력 가이드다.

## 1. 입력 방식
스킬을 요청할 때는 아래 정보만 주면 된다.

- 작업 이름
- 대상 파일 또는 폴더
- 원하는 결과물
- 제외할 것
- 검증 기준

## 2. 권장 입력 템플릿
```text
작업:
대상:
원하는 결과:
제외할 것:
검증 기준:
```

## 3. 스킬 목록
- `md_report`
- `folder_check`
- `doc_write`
- `db_check`

## 4. 스킬 선택 기준
- 문서를 새로 쓰거나 고치면 `md_report` 또는 `doc_write`
- 폴더와 파일 구조를 보면 `folder_check`
- DB 상태, 테이블, 쿼리를 보면 `db_check`

## 5. 공통 규칙
- 출력은 한국어로 쓴다.
- 깨진 인코딩이 보이면 먼저 바로잡는다.
- 삭제가 포함되면 범위를 먼저 확인한다.
- 결과가 여러 갈래면 실행 전에 확인 질문을 한다.
