# 음성대화 프론트 구현 보고서

## 변경 내용

- 상단 내비게이션을 정리해서 로고, 페이지 링크, 시계가 한 줄에서 가운데 정렬되도록 맞췄다.
- 하트 영역과 상단 모드 버튼은 화면에서 제거하고, `/chat`은 기존 동작을 유지했다.
- `/sensor` 화면은 조도 단위를 `%`로 맞추고, 그래프는 시간 단위로 묶어서 보여주도록 정리했다.
- settings 화면은 실제 TTS 음성 목록을 읽어서 Woman / Man 그룹으로 보여주고, 3개 페르소나 프리셋을 선택할 수 있게 바꿨다.

## 설정 저장 방식

- TTS voice 선택은 `localStorage`에 저장한다.
- 페르소나 프리셋도 `localStorage`에 저장한다.
- chat과 voice 요청은 같은 저장값을 읽어서 동일한 선택 상태를 사용한다.

## 센서 화면

- 상단 상태값의 조도는 `lux` 대신 `%`로 표시한다.
- 그래프는 최근 데이터를 시간 단위로 정리해서 보여준다.
- 축 범위는 온도 `0~40`, 습도/수위/조도 `0~100`으로 고정했다.

## 확인 항목

- `/chat`은 기존 흐름 그대로 동작해야 한다.
- `/sensor`에서 조도 표시는 `%`로 보여야 한다.
- settings에서 voice 개수와 persona 3종이 화면에 보여야 한다.
