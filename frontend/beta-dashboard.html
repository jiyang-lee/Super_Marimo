연결 주소

Docker compose를 올린 기본 포트입니다.

센서 테스트는 실시간 값과 시간당 값을 따로 넣고, 서버가 저장한 최신 병합 스냅샷을 확인하는 용도입니다. 대화 전송 시 센서 문맥을 켜면 이 최신값이 함께 전달됩니다.

실시간 센서 입력

거리와 조도는 호출어/접근 이벤트 판단에 바로 쓰이는 값입니다.

시간당 센서 입력

온도, 습도, 수위는 상태 설명과 장기 관찰용 DB 확인에 사용합니다.

센서 DB 조회

latest는 대화에 붙일 스냅샷, history는 DB에 값이 쌓이는지 보는 영역입니다.

{ "message": "센서 조회 전입니다." }

이벤트 DB는 호출어 감지, manual-test, TTS 생성, 재생 완료 상태가 저장되는지 확인하는 영역입니다. 행을 클릭하면 상세 JSON을 볼 수 있습니다.
