/sensor · Wemos 3초 주기 수집 대시보드

센서가 들어오는지, DB에 쌓이는지 한 화면에서 확인합니다.

이 페이지는 Wemos가 3초마다 읽어오는 realtime / hourly 값을 바로 보고, 아래에서는 PostgreSQL에 실제로 저장되는지를 확인하는 전용 점검 화면입니다. 위쪽은 현재값 카드, 아래쪽은 DB 저장 확인과 로그 위주로 배치했습니다.

검증 순서

  • Wemos 업로드 후 3초마다 realtime / hourly 전송 확인
  • 상단 카드에서 최신 센서값 확인
  • 하단 테이블에서 DB 저장 행이 늘어나는지 확인
  • 이벤트 / 세션 로그로 후속 상태까지 점검
기본 API: http://localhost:8000

DB 저장 상태 설명

realtime / hourly 데이터가 각각 sensor_readings에 저장되어야 합니다. realtime은 light, distance 중심이고, hourly는 temperature, humidity, water_level 중심입니다. 3초마다 전송되므로 최신 행의 timestamp가 자주 갱신되는지 먼저 확인하세요.
