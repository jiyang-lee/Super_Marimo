# Skills

이 폴더에는 반복 작업용 절차를 둔다.

## 목록
- `md_report.md`: 마크다운 보고서 작성
- `folder_check.md`: 폴더 구조 확인
- `doc_write.md`: 문서 작성
- `db_check.md`: DB 점검
- `beta_rollout.md`: 베타 전환 작업 절차
- `report_write.md`: 작업 종료 보고서 작성

## 사용 기준
- 새 기능이나 큰 수정이 있으면 먼저 작업 스킬을 고른다.
- 작업이 끝나면 `report_write`로 보고서를 쓴다.
- 베타 서비스 관련이면 `beta_rollout`을 우선 쓴다.
- 문서가 필요하면 `doc_write`를 쓴다.
- DB 상태가 중요하면 `db_check`를 쓴다.
