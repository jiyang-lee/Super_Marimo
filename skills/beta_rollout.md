# Beta Rollout Skill

베타 서비스로 가기 위한 백엔드 중심 작업에 쓴다.

## 언제 쓰는가
- 서버 역할을 다시 나눌 때
- 디바이스 이벤트 흐름을 정리할 때
- 호출어/거리센서/선제 인사 로직을 붙일 때
- GitHub 브랜치 작업과 함께 진행할 때

## 입력으로 필요한 것
- 현재 브랜치
- 바꿀 서버 이름
- 추가할 이벤트 종류
- 검증할 API
- 보고서 저장 경로

## 진행 순서
1. `main` 최신화
2. `backend/*` 브랜치 생성
3. 서버 역할 변경
4. 이벤트/로그/정책 추가
5. 검증
6. `docs/`에 보고서 작성
7. PR 생성

## 완료 기준
- 베타 핵심 흐름이 동작한다.
- 서버 역할이 문서와 일치한다.
- 디바이스 이벤트와 대화 로그가 구분된다.
- 작업 보고서가 남아 있다.
