# doc_write

## 언제 쓰나
- 프로젝트 문서를 새로 만들 때
- 기존 문서를 고칠 때
- 보고서, 가이드, 운영 문서를 정리할 때

## 사용자에게 받을 것
- 문서 제목
- 저장 경로
- 목적
- 대상 독자
- 포함할 항목

## 진행 순서
1. 문서 목적을 한 문장으로 정한다.
2. 필요한 항목을 순서대로 배치한다.
3. 한국어로 짧고 명확하게 쓴다.
4. 인코딩이 깨지지 않는지 확인한다.

## 출력 기준
- 제목과 목차가 자연스럽다.
- 중복 설명을 줄인다.
- 파일명이 내용과 맞는다.

## 완료 기준
- 바로 읽고 바로 쓸 수 있다.
