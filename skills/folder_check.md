# folder_check

## 언제 쓰나
- 현재 폴더 구조를 확인할 때
- 새 파일을 어디에 둘지 정할 때
- 프로젝트 안에 이미 있는 규칙이나 문서를 찾을 때

## 사용자에게 받을 것
- 확인할 루트 경로
- 보고 싶은 깊이
- 제외할 폴더
- 원하는 출력 형식

## 진행 순서
1. 루트 목록을 본다.
2. 관련 파일과 폴더를 찾는다.
3. 규칙 파일, 문서 파일, 테스트 파일을 우선 확인한다.
4. 필요한 경우 다음 작업 위치를 제안한다.

## 출력 기준
- 폴더 이름과 역할이 바로 보인다.
- 중요한 파일만 추려서 보여준다.
- 불필요한 전체 덤프는 피한다.

## 완료 기준
- 다음에 무엇을 건드려야 하는지 판단할 수 있다.
